# 📩 SpamShield AI — SMS Spam Detector

## 📌 About the Project

SpamShield AI is a Machine Learning project that detects whether an SMS message is Spam or Ham (Legitimate). It uses Natural Language Processing (NLP), TF-IDF vectorization, and the Multinomial Naive Bayes algorithm to classify messages.

The project provides a simple and interactive web interface built using Streamlit, allowing users to enter SMS messages and receive predictions.

## 🚀 Features

* Detect spam and legitimate SMS messages.
* Text preprocessing using NLP techniques.
* TF-IDF vectorization for text feature extraction.
* Machine Learning classification using Multinomial Naive Bayes.
* Interactive web interface using Streamlit.
* Instant predictions for user-entered messages.

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* Natural Language Processing (NLP)
* TF-IDF Vectorizer
* Multinomial Naive Bayes
* Streamlit
* Pickle
